# Student Task & Study Tracker

A student task tracker that lets students add tasks while setting a degree of priority for them.
The site is built with HTML, CSS, and JavaScript.

**Live Demo:** https://revert12-w.github.io/project/

# What does it do?
- You can add tasks with a priority tag (`High`, `Medium`, or `Low`)
- You can Mark tasks as done, or delete single tasks, or clear all completed tasks at once
- Tasks stay after refreshing the page

## Files
`index.html` — page layout
`style.css` —  page styling
`script.js` — task logic
